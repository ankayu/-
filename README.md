\# Main.exe



这是一个可直接运行的 Windows 程序。



\## 下载



请前往 \*\*Releases\*\* 页面下载最新版本：



\*\*\[下载最新版 main.exe](../../releases/latest)\*\*



下载完成后，将 `main.exe` 保存到 Windows 电脑上，然后双击即可运行。



\## 运行环境



\* Windows 10 / Windows 11

\* 无需安装 Python

\* 无需安装开发环境



\## 使用说明



1\. 从 Releases 下载 `main.exe`

2\. 将文件保存到电脑

3\. 双击 `main.exe`

4\. 如果 Windows Defender 或 SmartScreen 弹出安全提示，请根据你的实际情况选择是否允许运行
